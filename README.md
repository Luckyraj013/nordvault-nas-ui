# NordVault NAS UI

A responsive, SaaS-quality network storage experience with dedicated Admin and Employee workspaces.

## Highlights
- Storage pool, node health, throughput, uptime and live activity for administrators
- Personal storage, recent files, quick access and sharing updates for employees
- Light/dark themes and instant role switching
- Responsive desktop, tablet and mobile layouts
- Zero dependencies

## Run locally
Open `index.html` directly or run `python3 -m http.server 8080`.

## GitHub Pages
The included workflow deploys `main` to GitHub Pages. If needed, select **GitHub Actions** under **Settings → Pages → Source**.
